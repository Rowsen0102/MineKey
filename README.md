# 🔐 MineKey

MineKey — это веб-приложение для управления пользователями, файлами и VPN-ключами.

## 🚀 Возможности

### 👤 Пользователи

- Регистрация
- Авторизация
- JWT-аутентификация
- Просмотр профиля
- Редактирование профиля
- Загрузка аватара

### 📁 Файлы

- Загрузка файлов
- Просмотр списка файлов
- Скачивание файлов
- Удаление файлов

### 🔑 VPN

- Добавление VPN-ключей
- Получение свободного VPN
- Освобождение VPN
- Управление VPN через админ-панель

### 👑 Админ-панель

- Просмотр всех пользователей
- Редактирование пользователей
- Блокировка и разблокировка
- Удаление пользователей
- Статистика пользователей, файлов и VPN

## ▶️ Запуск проекта

### Backend

```bash
cd backend
npm install
npm start
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
